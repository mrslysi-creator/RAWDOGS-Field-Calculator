# RAWDOGS Field Calculator Build 2.4.1 — Coffee + Icon Preview

An **optional Windows desktop update**, alongside the preserved stable Build 2.4. Not a replacement for the original download.

## Exactly what changed
- Added a small **☕ BUY ME A COFFEE** button below the calculator's original footer; opens [creator's page](https://buymeacoffee.com/silvesta) only if clicked.
- Rebuilt the native 64-bit Windows launcher with the **original Build 2.4 RAWDOGS .ico embedded at compile time** and also included in the ZIP.
- Build 2.4.1 keeps extracted app files and browser profile separate from Build 2.4 under `%LOCALAPPDATA%`.
- Verified app maths/source data intentionally unchanged.

## Limits
Windows real-machine acceptance test still needed; **preview**, not a tested stable replacement. Extract ZIP to its own directory. No adverts, accounts, paid features, subscriptions or tracking; support is purely voluntary. Calculator remains otherwise offline.

[Original stable Windows Build 2.4](https://github.com/mrslysi-creator/RAWDOGS-Field-Calculator/raw/refs/heads/main/downloads/RAWDOGS_Field_Calculator_Build_2_4_Windows.zip) remains unchanged.
