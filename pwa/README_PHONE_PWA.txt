RAWDOGS FIELD CALCULATOR — PHONE / PWA

The mobile application has the same game-calibrated L81 mortar and SPH-2
calculation engine as the desktop and Windows versions.

Features
--------
- Original BLUE / RED / GREEN camouflage tiles and RAWDOGS icon.
- Manual firing-position and target coordinate entry.
- L81 mortar bearing, range and calibrated elevation.
- SPH-2 artillery low/high-arc solutions where available.
- Two stored firing-position presets A and B.
- Recall of recent targets, with a compact OLD TARGETS screen.
- NEW TARGET clears target coordinates while preserving firing position.
- Team selection is kept for the current app session.
- Offline-capable service worker after first successful load.
- No adverts, tracking, account requirement or subscription.

Open in a phone browser:
https://mrslysi-creator.github.io/RAWDOGS-Field-Calculator/

Use Add to Home Screen or Install App in a supported browser. Installable
service workers require HTTPS or localhost; they cannot register from file://.
