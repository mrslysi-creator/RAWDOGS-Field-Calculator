# Native Windows Voice-Controlled Preview v0.9.4

This directory stages the **original, unaltered 28 Oct 2026 Windows preview archive**. The base64 files are transport fragments, not individual programs. The GitHub Actions workflow reconstructs their exact ZIP bytes, checks SHA-256, validates its ZIP structure and makes the download available from the **v0.9.4-preview GitHub pre-release**.

[Download the v0.9.4 Windows EXE + source ZIP](https://github.com/mrslysi-creator/RAWDOGS-Field-Calculator/releases/download/v0.9.4-preview/RAWDOGS_Voice_Controlled_Field_Calculator_v0.9.4_Clean_Walkman_WINDOWS_EXE_AND_SOURCE.zip)

**Experimental status:** this preview is not a replacement for preserved Windows Build 2.4, the desktop web version, or the PWA. Windows user acceptance testing is pending.

SHA-256 (archive): `5655d1d7c0a83bbb8c0bfad3e5e555bac8b28716d773b4f204de514b1e32ab61`

The archive includes Go source, imagery, original EXE, README, indexed narration transcript, and tests. It does not bundle Piper/Vosk voice packs. This is a game-only tool for WARDOGS, not a real-world artillery fire-control system.
