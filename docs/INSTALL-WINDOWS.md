# Windows installation — RAWDOGS Field Calculator

## Download

[Download the Windows 64-bit application](https://github.com/mrslysi-creator/RAWDOGS-Field-Calculator/releases/download/v2.4.1-preview/RAWDOGS_Field_Calculator_Windows_2.4.1.zip)

## Install

1. Download the Windows ZIP from the link above.
2. **Extract all files** to a normal folder.
3. Double-click **`RAWDOGS Field Calculator.exe`**.
4. Select a team and enter firing-position and target coordinates.

The application contains the RAWDOGS icon and launches the calculator locally in Edge, Chrome or Brave app mode. The app extracts its embedded calculator to a local application data folder; it does **not** require a local web server or a persistent internet connection for calculations.

For Windows, this build is currently a **preview** while final compatibility checks are completed. Windows SmartScreen may prompt for an unsigned community executable. Obtain software only from this repository and verify the included `SHA256SUMS.txt` if needed.
