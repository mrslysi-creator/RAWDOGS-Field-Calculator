# Windows installation

## Recommended release

Use **RAWDOGS Field Calculator Build 2.4** as the current stable Windows build.

## Install / run

1. Download the Build 2.4 Windows ZIP from the repository Releases area.
2. Extract the ZIP to a normal folder.
3. Run the included RAWDOGS Field Calculator executable.
4. Keep the files in the extracted folder together unless the release notes say otherwise.

Windows may show a SmartScreen warning for an unsigned community application. Check that the file came from this official repository before running it.

Build 2.4 is being preserved unchanged while the source repository is populated.
